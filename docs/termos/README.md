# Termos de acesso aos microdados (não versionado)

Guarde aqui, fora do controle de versão (`.gitignore` bloqueia tudo em `docs/termos/` exceto este README):

- Termo de Compromisso de Confidencialidade e Responsabilidade (assinado).
- Termo de Uso e Finalidade aceito na solicitação de acesso controlado.
- E-mail/comprovante de concessão de acesso pelo IBGE.
- Eventual resposta do IBGE confirmando/aditando a finalidade para divulgação pública de resultados agregados (ver plano, "Ações do titular").

Este diretório existe para que a evidência de conformidade fique junto do projeto, sem nunca ser publicada.
